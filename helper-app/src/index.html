Create a Glean token

  1. Open Glean in your browser.
  2. Click the Glean logo in the bottom-left corner.
  3. Open Admin Console or Settings.
  4. Open API tokens.
  5. Create a Client API token.
  6. Add the CHAT and SEARCH scopes.
  7. Copy the token and paste it above.

Chrome extension

After installing or reloading the extension, click Pair extension. This prevents Unauthorized errors.

  1. Click Open extension folder. This copies the extension to your Desktop and opens Chrome extensions.
  2. Enable Developer Mode.
  3. Click Load unpacked.
  4. Choose Desktop, then select Gmail Glean Reply Extension.
  5. Click Pair extension to automatically save the local backend URL and secret. Do this any time you reinstall the app, rotate the secret, or see an Unauthorized error.
  6. Use Cmd+Shift+Y in a Gmail reply.
