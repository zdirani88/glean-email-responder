Connect Glean

Reply settings

Paste a Client API token, then test the connection.

Create a Glean token

  1. Open Glean in your browser.
  2. Click the Glean logo in the bottom-left corner.
  3. Open Admin Console or Settings.
  4. Open API tokens.
  5. Create a Client API token.
  6. Add the CHAT and SEARCH scopes.
  7. If your Glean admin exposes calendar action or Google Calendar access for Client API tokens, include it. If not, scheduling drafts will still ask Glean to use any tenant-enabled calendar action and will tell you to verify times when availability cannot be confirmed.
  8. Copy the token and paste it above.

Chrome extension

Copy or refresh the extension after every helper app update. The helper verifies the files, opens the copied folder and Chrome's extension page, and puts the folder path on your clipboard. Chrome still requires Load unpacked or Reload. Pairing opens the extension details page and copies values for its Options page.

  1. Click Install / refresh extension. Confirm the helper reports the current extension version.
  2. Enable Developer Mode.
  3. Click Load unpacked.
  4. Choose the copied folder path, then select Gmail Glean Reply Extension. If it is already installed, click its reload icon and confirm Chrome shows the current version.
  5. Click Pair extension. In Chrome, click Extension options, paste the two copied lines into the fields, and click Save. The helper then records the running extension version under “Chrome confirmed version.”
  6. Use Cmd+Shift+Y in a Gmail reply.

Manual steps to set up

Use these steps if automatic buttons or Chrome launch are blocked. The command is generated for this app and this Mac user. It tries your Desktop first, then uses a private writable app folder if Desktop access is restricted.

Preparing command...
  1. Copy the full command above, paste it into Terminal, and press Return.
  2. Open chrome://extensions in Chrome and turn on Developer mode.
  3. Choose Load unpacked for the first install, or click Reload on the existing extension.
  4. Select the Gmail Glean Reply Extension folder shown by the helper after copying.
  5. For pairing, open the extension's Options page. Paste the Backend URL into the first field and the Backend shared secret into the second field, then click Save.

The pairing values below are two separate lines: Backend URL first, Backend shared secret second. If a clipboard blocker prevents copying, select each line and type it into the matching Options field.
