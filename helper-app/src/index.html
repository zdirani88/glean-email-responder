How to create a Glean token
  1. Open Glean in your browser.
  2. Open Admin Console or Settings, then API tokens.
  3. Create a Client API token with the CHAT and SEARCH scopes.
  4. Copy the token and paste it above.

Set up the Chrome extension

Chrome requires you to approve locally installed extensions. Follow these steps once; this helper will automatically confirm the extension version after Chrome reloads it.

  1. Prepare the files. Click Prepare extension files. Finder will show the exact folder to use.
  2. Open Chrome’s extension page. In Chrome’s address bar, type chrome://extensions and press Return. Turn on Developer mode.
  3. Install or update. For a first install, click Load unpacked and select the folder Finder opened. If Glean Response Assistant is already listed, click its circular Reload icon.
  4. Connect the extension. Open its Details, then Extension options. Click Copy pairing values below; paste the first line as the backend URL and the second as the shared secret, then click Save.
